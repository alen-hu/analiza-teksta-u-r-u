# Analiza teksta u R-u

Quarto book na hrvatskom jeziku o osnovama analize teksta u programskom
jeziku R.

## Lokalno pokretanje

Za izradu HTML knjige potrebno je imati instalirane R i Quarto. U korijenu
projekta pokrenite:

```bash
quarto render
```

Izrađena knjiga bit će spremljena u direktorij `docs/`.
